# Task 2 - Responsive Productivity Dashboard

## Overview
This project was created for Task 2 of the ApexPlanet Web Development Internship Program.

## Features
- Responsive navigation bar using Flexbox
- Grid-based layout for content sections
- Contact form with JavaScript validation
- Dynamic to-do list using DOM manipulation

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone the repository
2. Open `index.html` in your browser
